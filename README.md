# Hospital Management System (C++)

A simple console-based Hospital Management System developed in C++.  
This project demonstrates basic Object-Oriented Programming concepts such as classes, objects, and data management.

## Features
- Admit a new patient
- Discharge a patient
- Update patient condition
- Display patient details
- View total number of patients
- Hire hospital staff
- Display staff details

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- Standard Template Library (STL basics)

## How It Works
The system allows users to manage hospital operations through a menu-driven interface in the terminal. Users can admit patients, update their medical condition, discharge them, and manage hospital staff.
